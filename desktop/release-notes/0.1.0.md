First native Windows version of Messenger.

- Same accounts, chats and messages as the web app
- Private and group chats, replies, edits, deletion, pinned messages
- Photos (with viewer), videos (open in your player), read receipts, typing and online status
- Profile, security, active sessions and admin panel
- Desktop notifications and automatic, signed updates

Voice calls are not available in the desktop app yet — use the web or Android app.
