# Messenger для Android

Первая Android-версия: устанавливаемое приложение на Java/WebView, использующее существующий HTTPS-сервер и веб-интерфейс. Android 8.0 или новее. Google Play не используется.

## Установка с GitHub

Готовый APK доступен в **Releases → Messenger Android → messenger-android.apk**, когда опубликован тег `android-v*`. SHA-256 лежит рядом. Альтернативно скачайте сборку из Actions:

1. Откройте вкладку **Actions → Android APK**, выберите успешную сборку ветки с Android-проектом.
2. Скачайте артефакт **messenger-android-debug** (нужен вход в GitHub), распакуйте ZIP.
3. Перенесите `app-debug.apk` на телефон и откройте. Разрешите установку из выбранного браузера или файлового менеджера.
4. Включите Tailscale и подключитесь к сети сервера. Адрес по умолчанию: `https://messenger-01.tail1a26d2.ts.net`. Кнопка **Messenger · Сервер** позволяет указать другой HTTPS-сервер.
5. Войдите в существующий аккаунт. Для звонков разрешите микрофон по запросу; файлы выбираются системным диалогом.

Это тестовый APK с debug-подписью. Ключ на разных GitHub runners может отличаться: для новой сборки может понадобиться удалить предыдущую установку (локальная сессия потеряется; чаты остаются на сервере). Для стабильных обновлений необходим отдельный постоянный ключ подписи, хранящийся в GitHub Secrets, а не в репозитории.

## Локальная сборка

Нужны JDK 17, Android SDK Platform 35, Build Tools и Gradle 8.11.1. Откройте папку `android` в Android Studio либо задайте `ANDROID_HOME` и выполните:

```sh
cd android
gradle :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Возможности и ограничения

- Аккаунты, личные чаты, группы и профили используют интерфейс и API работающего сервера.
- Выбор изображений/видео и запрос разрешения микрофона реализованы в Android-оболочке.
- HTTPS обязателен; ошибки сертификатов не обходятся. Внешние HTTPS-ссылки открываются браузером.
- Нет push-уведомлений, офлайн-чатов, гарантированного приёма звонков в фоне или при закрытом приложении.
- Обновления веб-интерфейса приходят с сервера без замены APK.
- Проверка на физическом Android-устройстве нужна для звонков, клавиатуры, вложений и поведения конкретного Android System WebView.
